# Third-party data notices

Unclaimable.Extended embeds transformed name/identity lists from the following public datasets. The package stores only fields needed for identifier protection and does not reproduce unrelated source fields.

## U.S. Securities and Exchange Commission

Company names are derived from the SEC public company/ticker reference dataset (`company_tickers_exchange.json`). The source of record is the U.S. Securities and Exchange Commission. Company names and related registry facts are used as factual reference data.
